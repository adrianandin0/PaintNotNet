# PaintNotNet

> ⚠️ **Work in Progress:** Este proyecto está en desarrollo activo y se irá actualizando con frecuencia.

Un editor de imágenes liviano escrito en Python y PyQt6, pensado como una alternativa simple tipo Paint.NET.

## ¿Qué tiene hasta ahora?
* **Herramientas básicas:** Lápiz, pincel con suavizado, goma, balde de pintura y texto con sombras/bordes.
* **Selección y transformaciones:** Podés mover, estirar, rotar y voltear selecciones o imágenes insertadas.
* **Deshacer y Rehacer:** Historial funcional con Ctrl+Z y Ctrl+Y que respeta las selecciones activas.
* **Manejo de imagen:** Cambiar tamaño del lienzo, reescalar imágenes y soporte para transparencias.

## Cómo usarlo

**Desde el ejecutable compilado:**
./dist/PaintNotNet

**Desde el código fuente:**
source venv/bin/activate
python main.py
