# Código de Conducta de PaintNotNet / PaintNotNet Code of Conduct

---

## Español

El espíritu fundamental detrás de PaintNotNet es crear un entorno de creatividad, colaboración y aprendizaje constante. A todos los miembros de la comunidad, usuarios y desarrolladores, les pedimos que sigan estos principios:

### 1. Uso Responsable y Ético
Se otorga total libertad para utilizar PaintNotNet con fines personales, educativos y comerciales. Todo usuario se compromete a dar un uso ético, legal y constructivo a la aplicación y a las imágenes generadas con ella. Fomentamos la creatividad positiva.

### 2. Colaboración y Mejora Continua
El núcleo de este proyecto es el aprendizaje libre y la evolución. Invitamos cálidamente a toda la comunidad a colaborar:
- Reportando errores de forma respetuosa.
- Sugiriendo nuevas funciones o mejoras.
- Contribuyendo directamente al código fuente para hacer del programa un software cada vez más completo.

### 3. Respeto en la Comunidad
Cualquier interacción en foros, issues, o pull requests debe hacerse desde el respeto, la empatía y la colaboración. No toleramos el acoso, los insultos o el menosprecio hacia las dudas o contribuciones de otros usuarios, por más pequeñas que sean.

¡Gracias por apoyar a PaintNotNet y hacer de nuestra comunidad un lugar mejor!

---

## English

The fundamental spirit behind PaintNotNet is to create an environment of creativity, collaboration, and continuous learning. We ask all community members, users, and developers to follow these principles:

### 1. Responsible and Ethical Use
Full freedom is granted to use PaintNotNet for personal, educational, and commercial purposes. Every user agrees to make an ethical, legal, and constructive use of the application and the images generated with it. We encourage positive creativity.

### 2. Collaboration and Continuous Improvement
The core of this project is open learning and evolution. We warmly invite the entire community to collaborate by:
- Reporting bugs respectfully.
- Suggesting new features or improvements.
- Contributing directly to the source code to make the program an increasingly complete software.

### 3. Respect in the Community
Any interaction in forums, issues, or pull requests must be done with respect, empathy, and collaboration. We do not tolerate harassment, insults, or disrespect towards the questions or contributions of other users, no matter how small they may be.

Thank you for supporting PaintNotNet and making our community a better place!
